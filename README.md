# Giobbi's ⚡

> O parceiro certo, no momento certo.

Plataforma que conecta empresas de varejo a colaboradores verificados e qualificados para turnos flexíveis em supermercados, atacarejos e dark stores.

## Stack

- React 18
- Vite 5
- CSS-in-JS (inline styles + CSS classes injetadas dinamicamente)
- Fontes: Cabinet Grotesk + General Sans via Fontshare

## Rodar localmente

```bash
npm install
npm run dev
```

## Build para produção

```bash
npm run build
```

## Deploy

Conecte o repositório ao [Vercel](https://vercel.com). O deploy é automático a cada push na branch `main`.

Framework preset: **Vite**
